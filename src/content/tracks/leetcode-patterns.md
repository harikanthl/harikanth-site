Every episode has three artefacts: a prep sheet (the written version of the video), a
solution file with the tests written *before* the code, and the video itself. The
pattern cards explain when to reach for each pattern, in plain language, before any
problem is attempted.

Solutions are re-solved from scratch on a 1 → 3 → 7 → 16 → 35 → 90 day ladder. A
problem I can rebuild after 90 days is one I actually own.
